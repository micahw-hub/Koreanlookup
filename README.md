# Korean Lookup on GitHub Pages

1. On github.com, create a new repository (public is fine; it contains no secrets).
2. Click Add file, then Upload files, drag in everything from this folder
   (index.html, shim.js, sw.js, manifest.webmanifest and the three icons), and commit.
3. Go to Settings, then Pages. Under Build and deployment choose
   "Deploy from a branch", pick the main branch and the / (root) folder, and save.
4. After a minute your site is live at https://YOUR-USERNAME.github.io/YOUR-REPO/

## First use
The page asks once for your Anthropic API key and saves it only in that browser.
Never paste your key into any of the files or share your key with others.
On iPhone use Share, then Add to Home Screen; on Android use menu, then Install app.

## Good to know
- Each person who uses the site needs their own API key, and lookups are billed to that key.
- History is saved per browser and doesn't sync between devices.
